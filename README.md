# Damiyah's Cookie Crush

Website for Damiyah's Cookie Crush: homemade cookies & sweet treats in Richmond, VA (VCU area).

- Orders are booked by Instagram DM: [@damiyahscookiecrush](https://www.instagram.com/damiyahscookiecrush)
- Payments: Cash App, Venmo, PayPal, cash

It's a single static page (`index.html` + `img/logo.png`) with no build step, hosted with GitHub Pages.
